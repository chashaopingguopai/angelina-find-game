# 把星星都找遍：安洁莉娜在哪里？

一款使用 React + Vite 制作的《明日方舟》安洁莉娜同人找图小游戏。观察每轮目标图片，在倒计时结束前从图片网格中找到唯一正确的安洁莉娜。

> 本项目为非商业、非官方的粉丝二次创作，仅用于学习、交流与娱乐。

## 在线游玩

[angelina-find-game.netlify.app](https://angelina-find-game.netlify.app)

## 游戏模式

- **15 轮挑战**：包含 5 个难度阶段，每阶段固定 3 轮；完成后根据总用时获得 S、A、B 或 C 评级。
- **无限模式**：没有固定轮数，持续挑战逐渐增加的图片数量和逐渐缩短的单轮时间。
- 每轮目标图片只出现一次，干扰图片和位置随机生成。
- 点击正确图片进入下一轮；点击错误图片不会立即结束游戏。
- 完成或中途结束后，会根据评级或完成进度显示对应结算评语。

## 技术栈

- React 19
- Vite 8
- 现代 JavaScript（ES6+）
- 原生 CSS 响应式布局与动画
- Netlify 部署

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## Netlify 部署

项目已提供 `netlify.toml`：

- 构建命令：`npm run build`
- 发布目录：`dist`
- SPA 路径统一回退至 `index.html`
